# Гений нестандартного маркетинга

Плагин для разработки нестандартных идей привлечения клиентов, внутренних продаж и простых автоматизаций бизнеса.

**Автор и разработчик: Ольга Кандакова.**  
Версия: **0.3.5**.

## Что умеет

- Уточняет задачу и особенности бизнеса.
- Исследует покупательские мотивы и барьеры.
- Предлагает идеи внешнего привлечения и внутренних продаж.
- Помогает разработать бюджетные тесты и показатели результата.
- Предлагает простые идеи автоматизации для бизнеса.

## Начать работу

После установки выберите плагин через @ и напишите, например:

> У меня канцелярский магазин в Тюмени, есть доставка. Предложи 10 нестандартных способов привлечь клиентов из соседних районов и 3 простые идеи автоматизации.

## Установка и доступ

Этот репозиторий содержит файлы плагина и манифест marketplace. Ссылка GitHub открывает исходники; она не устанавливает плагин автоматически и не меняет доступ к личной копии автора в ChatGPT.

### Импорт в рабочее пространство ChatGPT

Потребуются права администратора рабочего пространства и доступная функция импорта marketplace:

1. Откройте **Admin → Plugins → Add → Import marketplace**.
2. В **Source** укажите: https://github.com/prodakshnemoji-cell/genius-nonstandard-marketing
3. **Path** оставьте пустым. **Branch** — main или оставьте пустым.
4. Выполните импорт и настройте доступ к плагину.
5. Пользователи устанавливают импортированный плагин и начинают новый чат.

[Официальная инструкция OpenAI](https://learn.chatgpt.com/docs/enterprise/plugin-management)

### Личный аккаунт

Наличие личного аккаунта ChatGPT и ссылки GitHub не гарантирует возможность импорта. Если функции импорта нет, описанный способ для рабочего пространства не подойдёт. Для Codex используйте поддерживаемую вашим клиентом настройку marketplace.

[Плагины и поддерживаемые способы установки](https://learn.chatgpt.com/docs/plugins)

## Состав

- `plugin.json` — переносимый манифест.
- `.codex-plugin/plugin.json` — манифест совместимости.
- `.agents/plugins/marketplace.json` — каталог для импорта.
- `skills/` — восемь сценариев работы.
- `references/` — инструкции и справочные материалы.
